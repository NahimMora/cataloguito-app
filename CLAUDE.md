# Orientación para Claude Code

Usar las reglas compartidas importadas. El fundador autorizó implementar el MVP de fase 1 y probarlo localmente. Producción requiere autorización específica.

Para tareas visuales posteriores autorizadas, consultar DESIGN_SYSTEM.md y los contratos de PRODUCT.md/ARCHITECTURE.md. Trabajar con componentes Blade, estados reales y estilos comunes; no introducir React, SPA, un nuevo sistema de diseño o librerías pesadas por comodidad.

El ticket define archivos asignados. Si una vista requiere un contrato backend nuevo, coordinarlo antes de editar rutas/controladores o lockfiles compartidos. Documentar estados vacío, carga, error, guardado y conflicto. Entregar evidencia visual móvil y accesibilidad de teclado.

La importación explícita mantiene una sola política compartida y es adecuada en Windows. Ver documentación oficial: https://code.claude.com/docs/en/memory . No duplicar aquí reglas generales ni modificar las del otro agente sin registrar el cambio.
